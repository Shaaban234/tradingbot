Binance connection test for Vercel (no API key needed, places no orders).
1. Upload this folder to a new GitHub repo (or run: npx vercel --prod inside it).
2. Import the repo in Vercel and deploy.
3. Open https://YOUR-PROJECT.vercel.app/api  and send the result to Claude.
vercel.json pins the region to Dubai (dxb1). Change to "bom1" (Mumbai) or "fra1" (Frankfurt) to try others.
